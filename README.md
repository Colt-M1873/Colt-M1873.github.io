# NerdyResearch

Source for [colt-m1873.github.io](https://colt-m1873.github.io/), built with [Hugo](https://gohugo.io/) and the [PaperMod](https://github.com/adityatelange/hugo-PaperMod) theme.

## Local development

```bash
hugo server -D
```

Deployment to GitHub Pages is automated via `.github/workflows/hugo.yml` on every push to `master`.
